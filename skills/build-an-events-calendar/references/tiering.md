# Tiering the calendar

| Tier | Test | Action |
|---|---|---|
| Must-do | buyers and category present, fits budget, passed vet-a-trade-show-before-exhibiting | book space or a package |
| Maybe | fit is likely but unchecked, or the price is unknown | ask the organizer the questions in vet-a-trade-show-before-exhibiting |
| Watch | new show, thin list, or a competitor-only signal | attend without a booth once, count the buyers on the floor |

Spread must-dos so the team can follow up on leads from one show before the next. Put a review date after each show:
meetings held, pipeline opened, and whether to rebook.
